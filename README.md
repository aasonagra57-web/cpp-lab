# C++ Lab Programs

A collection of C++ programs developed while practicing programming concepts and completing laboratory exercises.

## 📚 Topics Covered

- Basic input and output
- Conditional statements and loops
- Functions and arrays
- Classes and objects
- Object-oriented programming
- Operator overloading
- Inheritance and polymorphism

*The topics listed above should be updated to match the programs available in this repository.*

## 🎯 Purpose

- Practice C++ programming.
- Strengthen problem-solving skills.
- Understand programming concepts through practical examples.
- Maintain an organized record of laboratory work.

## ▶️ How to Run

1. Install a C++ compiler, such as GCC.
2. Open a terminal in the folder containing a program.
3. Compile the program:

   ```bash
   g++ filename.cpp -o program
   ```

4. Run the compiled program on Windows:

   ```bash
   .\program.exe
   ```

Replace `filename.cpp` with the actual source filename.
